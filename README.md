# 候鸟

候鸟是一款面向校招求职者的秋招管理网站，用来集中记录投递、关键截止时间、网申资料、简历版本和面试复盘。

## 当前功能

- 按公司、岗位和招聘阶段管理投递记录
- 为每条投递关联当时使用的简历版本
- 汇总今日面试、笔试和截止提醒
- 维护可复用的网申个人信息
- 记录面试题目与复盘笔记
- 适配桌面端和移动端浏览器

## 本地开发

需要 Node.js 22.13 或更高版本。

```bash
pnpm install
pnpm dev
```

构建与数据库迁移：

```bash
pnpm db:generate
pnpm build
```

结构化数据使用 Cloudflare D1，数据库定义位于 `db/schema.ts`，迁移文件位于 `drizzle/`。
